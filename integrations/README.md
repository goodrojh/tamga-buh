# Приём заявок: Google-таблица + e-mail + Telegram-бот

Сайт статический (GitHub Pages), поэтому «сервером» служит бесплатный **Google Apps Script** —
скрипт внутри Google-таблицы. Каждая заявка с сайта попадает:

1. в **Google-таблицу** (лист «Заявки») — журнал всех лидов;
2. на **e-mail** `korney88_elista@mail.ru`;
3. в **Telegram** — сообщение от бота лично заказчику (и тем, кого добавите позже).

Бот пишет **только** тем chat_id, которые вы впишете в настройки. Посторонний человек, нажавший
в боте «Start», ничего не получит — бот ему просто не отвечает.

Всё бесплатно. Понадобятся: аккаунт Telegram, аккаунт Google (лучше заказчика — тогда таблица будет его).

## Часть A. Telegram-бот

### A1. Создать бота

1. В Telegram в поиске введите `BotFather`, откройте бота с синей галочкой **@BotFather**.
2. Нажмите **Start** (или отправьте `/start`).
3. Отправьте команду: `/newbot`
4. Бот спросит имя. Отправьте: `ТамгаБух Заявки`
5. Бот спросит username (латиницей, заканчивается на `bot`). Отправьте, например: `tamgabuh_leads_bot`
   Если занято — придумайте другой: `tamgabuh_zayavki_bot`, `tamga_buh_bot` и т.п.
6. BotFather ответит «Done! Congratulations…» и пришлёт строку вида
   `123456789:AAH1bGciOiJIUzI1NiJ9…` — это **токен**. Скопируйте его целиком и сохраните.
   Никому не показывайте: у кого токен — тот управляет ботом.

### A2. Чтобы заказчик получал заявки

1. Отправьте заказчику ссылку на бота: `https://t.me/tamgabuh_leads_bot` (подставьте свой username).
2. Заказчик открывает бота и нажимает **Start**, потом пишет боту любое слово, например `привет`.
   (Без этого Telegram не даст боту писать ему первым.)
3. Если хотите получать копии заявок и вы — сделайте то же самое со своего аккаунта.

Chat_id узнаем в части C, скрипт сам его покажет.

## Часть B. Google-таблица и скрипт

Вы написали, что код уже вставили. Но я его дорабатывал — **вставьте заново** актуальную версию,
чтобы работали несколько получателей и помощник `getChatIds`.

1. Откройте https://sheets.new — создастся новая таблица. Назовите её `ТамгаБух — Заявки`
   (клик по «Новая таблица» слева сверху → ввести название).
2. Меню **Расширения → Apps Script**. Откроется редактор в новой вкладке.
3. В редакторе слева файл `Код.gs`. Кликните в область кода, нажмите **Ctrl+A**, затем **Delete**.
4. Откройте файл `integrations/google-apps-script/Code.gs` из проекта (например, в Блокноте или на GitHub:
   https://github.com/goodrojh/tamga-buh/blob/main/integrations/google-apps-script/Code.gs → кнопка «Raw»),
   выделите всё (**Ctrl+A**), скопируйте (**Ctrl+C**), вставьте в редактор (**Ctrl+V**).
5. Нажмите **Ctrl+S** (или иконку дискеты). Вверху можно переименовать проект: клик на «Проект без названия» → `Заявки ТамгаБух`.

## Часть C. Настройки (токен, chat_id, почта)

> **Короткий путь:** все три значения можно вписать прямо в начало файла `Code.gs`, в блок `CONFIG`
> (`TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `EMAIL_TO`). Тогда Свойства скрипта не нужны — переходите к части D.
> Свойства скрипта надёжнее (токен не лежит в коде), но для старта CONFIG достаточно.

### C1. Токен бота и e-mail

1. В редакторе Apps Script слева нажмите **⚙ Настройки проекта** (шестерёнка).
2. Прокрутите вниз до блока **Свойства скрипта** → кнопка **Добавить свойство**.
3. Добавьте по очереди (кнопка «Добавить свойство» для каждого):

   | Свойство (левое поле) | Значение (правое поле) |
   |---|---|
   | `TELEGRAM_BOT_TOKEN` | токен из шага A1, целиком, без пробелов |
   | `EMAIL_TO` | `korney88_elista@mail.ru` |

4. Нажмите **Сохранить свойства скрипта**.

### C2. Узнать chat_id заказчика (скрипт покажет сам)

1. Вернитесь в редактор: слева **< > Редактор**.
2. Вверху над кодом есть выпадающий список функций (там написано `doGet` или `setup`).
   Выберите в нём **`getChatIds`**.
3. Нажмите **▶ Выполнить**.
4. **Первый раз** Google попросит разрешения:
   - «Требуется авторизация» → **Проверить разрешения**
   - выберите свой Google-аккаунт
   - появится «Google не проверял это приложение» → нажмите маленькую ссылку **Дополнительные настройки**
     (Advanced) → внизу **Перейти к «Заявки ТамгаБух» (небезопасно)** → **Разрешить**.
   Это нормально: «непроверенное приложение» — это ваш собственный скрипт.
5. Внизу откроется **Журнал выполнения**. Там будет что-то вроде:
   ```
   Найдены чаты:
     chat_id = 123456789   —   Личный чат: Корней Надвидов (@korney88_elista)
     chat_id = 987654321   —   Личный чат: Владос (@ваш_ник)
   ```
   Если написано «Пока никто не писал боту» — значит, заказчик ещё не нажал Start и не написал боту
   (шаг A2). Пусть напишет, и запустите `getChatIds` ещё раз.
6. Скопируйте chat_id заказчика.

### C3. Вписать получателей

1. Снова **⚙ Настройки проекта → Свойства скрипта → Добавить свойство**:

   | Свойство | Значение |
   |---|---|
   | `TELEGRAM_CHAT_ID` | chat_id заказчика, например `123456789` |

   Если получателей несколько — через запятую без пробелов: `123456789,987654321`.
2. **Сохранить свойства скрипта**.

> **Добавить человека потом:** он открывает бота → Start → пишет любое слово; вы запускаете `getChatIds`,
> берёте его chat_id и дописываете через запятую в `TELEGRAM_CHAT_ID`. Код не трогаете, переразвёртывать
> не нужно. Убрать — удалить его id из этой же строки.

## Часть D. Проверка

1. В редакторе выберите функцию **`setup`** → **▶ Выполнить**. В таблице появится лист «Заявки» с шапкой.
2. Выберите функцию **`testLead`** → **▶ Выполнить**. Через 5–10 секунд:
   - в таблице появится строка «Тест»;
   - на `korney88_elista@mail.ru` придёт письмо «Заявка с сайта ТамгаБух» (проверьте папку «Спам»);
   - заказчику в Telegram придёт сообщение от бота.
3. Если чего-то нет — в **Журнале выполнения** будет строка вида
   `{"ok":true,"results":{"sheet":true,"telegram":"123456789: sent","email":"sent"}}`.
   Где не `sent` — там и причина (см. «Частые ошибки» внизу).

## Часть E. Опубликовать скрипт как веб-приложение

Это даёт ссылку, на которую сайт будет отправлять заявки.

1. Справа вверху синяя кнопка **Начать развёртывание → Новое развёртывание**.
2. Слева от «Выберите тип» нажмите **⚙** → **Веб-приложение**.
3. Заполните:
   - Описание: `leads`
   - **Запуск от имени:** `Я (ваш e-mail)`
   - **У кого есть доступ:** `Все` ← обязательно именно «Все», иначе сайт не сможет отправлять
4. **Начать развёртывание**. Возможно, снова попросит разрешения — разрешите как в C2.
5. Появится **URL веб-приложения** вида
   `https://script.google.com/macros/s/AKfycb…/exec` — нажмите **Копировать**.
6. Проверка: вставьте этот URL в адресную строку браузера → должно показать
   `{"ok":true,"service":"tamga-buh leads"}`.

## Часть F. Подключить к сайту

1. Откройте файл `tamga-buh/src/config/site.ts`.
2. Найдите строку `formEndpoint: '',` и вставьте URL между кавычками:
   ```ts
   formEndpoint: 'https://script.google.com/macros/s/AKfycb…/exec',
   ```
3. Сохраните и опубликуйте сайт:
   ```bash
   cd "D:\games\Cloude\Бухгалтерские услуги Калмыкия\tamga-buh"
   npm run deploy
   ```
4. Через 1–2 минуты откройте https://goodrojh.github.io/tamga-buh/, нажмите любую кнопку «Заказать звонок»,
   отправьте тестовую заявку со своим номером. Должны прийти: строка в таблице, письмо, сообщение в Telegram.

Либо просто пришлите мне URL из шага E5 — впишу и задеплою сам.

## Что попадает в таблицу

| Колонка | Что там |
|---|---|
| Дата и время | момент заявки |
| Имя, Телефон, Тема, Комментарий | что ввёл клиент; тема = с какой кнопки пришёл (тариф, калькулятор с расчётом, услуга) |
| Кнопка (источник) | техническая метка кнопки на сайте |
| Страница, UTM *, Реферер | откуда пришёл посетитель — для оценки рекламы |
| Устройство | телефон / компьютер |
| ID заявки | короткий номер, он же в Telegram и письме |

Скрипт только дописывает строки и ничего в таблице не меняет.

## Если что-то поменялось

- Изменили `Code.gs` → **Начать развёртывание → Управление развёртываниями → ✎ (карандаш) → Версия: «Новая версия» → Развернуть**. URL остаётся прежним.
- Сменили токен / почту / получателей → только **Свойства скрипта**, код и развёртывание не трогаете.
- Лимиты бесплатного Google: ~100 писем в день, ~20 000 запросов в день — хватит с большим запасом.

## Частые ошибки

- **`telegram: … chat not found`** — этот chat_id не нажимал Start у бота, или id с опечаткой.
- **`telegram: … bot was blocked by the user`** — человек заблокировал бота, пусть разблокирует.
- **`email: … `** ошибка или письма нет — проверьте «Спам» на mail.ru и что `EMAIL_TO` без пробелов.
- **На сайте «Не получилось отправить»** — откройте URL веб-приложения в браузере: если не `{"ok":true}`,
  переразверните с доступом «Все» (часть E).
- **«Пока никто не писал боту»** в `getChatIds` — заказчик должен именно *написать* боту, одного Start иногда мало.
