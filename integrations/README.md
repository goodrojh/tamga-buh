# Приём заявок: Google-таблица + e-mail + Telegram-бот

Сайт статический (GitHub Pages), поэтому бэкендом служит бесплатный **Google Apps Script**.
Одна заявка с сайта → одним запросом попадает:

1. в **Google-таблицу** (лист «Заявки») — журнал всех лидов с датой, контактами и UTM-метками;
2. на **e-mail** `korney88_elista@mail.ru` (или любой другой);
3. в **Telegram** — сообщение от бота в личный чат или группу.

Настройка занимает ~15 минут, ничего платного не нужно. Делать лучше **из Google-аккаунта заказчика**,
чтобы таблица и скрипт принадлежали ему.

---

## Шаг 1. Telegram-бот (5 минут)

1. В Telegram откройте **@BotFather** → `/newbot`.
2. Имя: `ТамгаБух Заявки`, username: например `tamgabuh_leads_bot` (должен оканчиваться на `bot`).
3. BotFather пришлёт **токен** вида `123456789:AAH...`. Сохраните — это `TELEGRAM_BOT_TOKEN`.
4. Куда слать заявки:
   - **В личку:** откройте своего бота, нажмите **Start** и напишите ему любое сообщение.
   - **В группу** (удобно, если заявки смотрят несколько человек): создайте группу, добавьте бота, напишите в группу любое сообщение.
5. Узнайте **chat_id**: откройте в браузере
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates`
   и найдите `"chat":{"id": ...}`. Для лички это положительное число, для группы — отрицательное (`-100...`).
   Это `TELEGRAM_CHAT_ID`.

> Если `getUpdates` пустой — напишите боту ещё раз и обновите страницу.

## Шаг 2. Google-таблица

1. Создайте новую таблицу на https://sheets.new, назовите `ТамгаБух — Заявки`.
2. Меню **Расширения → Apps Script**. Откроется редактор скриптов, привязанный к этой таблице.
3. Удалите содержимое `Код.gs` и вставьте целиком файл **`google-apps-script/Code.gs`** из этой папки. Сохраните (Ctrl+S).

## Шаг 3. Секреты

В редакторе Apps Script: **⚙ Настройки проекта → Свойства скрипта → Добавить свойство**:

| Свойство | Значение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен из шага 1 |
| `TELEGRAM_CHAT_ID` | chat_id из шага 1 |
| `EMAIL_TO` | `korney88_elista@mail.ru` (можно несколько через запятую) |
| `SECRET` | *(необязательно)* любое слово, например `tamga2026` — защита от чужих запросов |

`SHEET_ID` задавать не нужно — скрипт привязан к таблице.

## Шаг 4. Первый запуск и проверка

1. В редакторе выберите функцию **`setup`** в выпадающем списке и нажмите **▶ Выполнить**.
   Google попросит разрешения (таблицы, почта, внешние запросы) — **разрешите** (Advanced → Go to project (unsafe) → Allow).
   Лист «Заявки» получит шапку и закреплённую первую строку.
2. Выберите функцию **`testLead`** → **▶ Выполнить**. Должно появиться:
   строка в таблице, письмо на почту и сообщение в Telegram.
   Если что-то не пришло — смотрите **Журнал выполнения** внизу: там будет причина (`telegram: http 400 ...` и т.п.).

## Шаг 5. Публикация веб-приложения

1. **Развернуть → Новое развёртывание → ⚙ Тип: Веб-приложение**.
2. Описание: `leads`, **Запуск от имени: Я**, **У кого есть доступ: Все**. → **Начать развёртывание**.
3. Скопируйте **URL веб-приложения** вида `https://script.google.com/macros/s/AKfy.../exec`.
4. Проверка: откройте этот URL в браузере — должно показать `{"ok":true,"service":"tamga-buh leads"}`.

## Шаг 6. Подключить к сайту

В файле `src/config/site.ts`:

```ts
formEndpoint: 'https://script.google.com/macros/s/AKfy.../exec',
```

Если задали `SECRET` — впишите то же слово в `formSecret` там же.

Затем:

```bash
npm run deploy
```

Через 1–2 минуты отправьте тестовую заявку с сайта. Пока `formEndpoint` пустой, сайт работает в резервном
режиме: заявка открывает WhatsApp с готовым текстом.

## Что попадает в таблицу

| Колонка | Что там |
|---|---|
| Дата и время | момент заявки |
| Имя, Телефон, Тема, Комментарий | что ввёл клиент; тема = с какой кнопки пришёл (тариф, калькулятор с расчётом, услуга) |
| Кнопка (источник) | техническая метка кнопки на сайте |
| Страница, UTM *, Реферер | откуда пришёл посетитель — для оценки рекламы |
| Устройство | телефон / компьютер |
| ID заявки | короткий номер, он же в Telegram и письме |

Таблица — только журнал лидов. Скрипт в неё лишь дописывает строки и ничего не меняет,
поэтому её можно безопасно подключить к любой CRM позже (импорт или интеграция по Google Sheets).

## Если что-то поменялось

- Изменили `Code.gs` → **Развернуть → Управление развёртываниями → ✎ → Версия: новая → Развернуть**. URL не меняется.
- Сменили токен/почту → правьте только Свойства скрипта, код трогать не нужно.
- Лимиты бесплатного Google: ~100 писем в день и ~20 000 запросов в день — для сайта услуг с запасом.

## Частые ошибки

- **Письма не приходят** — проверьте папку «Спам» на mail.ru и что `EMAIL_TO` без пробелов.
- **Telegram: `chat not found`** — боту не написали «Start» или не тот chat_id (для группы — с минусом).
- **Telegram: `bot was blocked`** — бот заблокирован в чате, разблокируйте.
- **На сайте «Не получилось отправить»** — откройте URL веб-приложения в браузере: если не `{"ok":true}`,
  переразверните с доступом «Все».
